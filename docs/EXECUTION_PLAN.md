## الجزء ١ — البنية المعيارية (Modular Monolith)

### القاعدة الحاكمة

**نواة واحدة · محوّلات متعددة.** المنتجات (هالة سلة / زد / المواقع / واتساب) ليست
أربعة مشاريع — بل نواة واحدة بأربعة محوّلات. لحظة انفصال الشيفرة تنفصل اللهجة،
وهي الأصل الاستراتيجي الوحيد.

### الطبقات (موجودة فعلاً — نثبّتها، لا نعيد بناءها)

```
functions/
  _lib/
    core/          ← الحوكمة: session · auth · meter · rateLimit · respond · security · db
    ai/            ← النواة الذكية: persona · gateway · memory · intents
    integrations/  ← المحوّلات: salla · zid · trendyol · whatsapp · dlq
  api/             ← نقاط الدخول: تُنسّق فقط، لا تحتوي منطقاً
```

### قواعد المعيارية الخمس (تُفحص بأي مراجعة كود)

| # | القاعدة | لماذا |
|---|---|---|
| M1 | **`api/*` تنسّق فقط** — لا منطق أعمال داخل نقطة الدخول | نقطة الدخول تتغير مع القناة؛ المنطق لا |
| M2 | **الشخصية مصدر واحد** (`ai/persona.js`) — أي قناة جديدة تستوردها، لا تنسخها | نسخة ثانية = لهجتان تتباعدان |
| M3 | **كل تكامل خارجي خلف محوّل** في `integrations/` بواجهة موحّدة | تغيّر API خارجي = ملف واحد يتعدّل |
| M4 | **الحوكمة إجبارية على كل مسار AI**: `resolveStoreId` + `checkAndConsumeMonthly` | ٦ نقاط اليوم تستدعي AI بلا حصة — دَين موثّق |
| M5 | **لا حالة عامة (global state)** بين الطلبات — بيئة Workers لا تضمنها | مصدر أعطال صامتة يصعب تتبعها |

### واجهة المحوّل الموحّدة (عقد ثابت لأي قناة جديدة)

كل محوّل قناة يصدّر نفس الأسماء بالضبط:

```js
// integrations/<channel>.js
export function isConfigured(env)              // هل الأسرار موجودة؟
export async function receive(request, env)    // تحقق التوقيع → رسالة موحّدة
export async function send(env, to, text)      // إرسال
export async function fetchContext(env, id)    // بيانات المصدر (منتجات/طلبات) — اختياري
```

**قيمة العقد:** إضافة إنستغرام أو تيك توك = ملف واحد جديد يحقق هذا العقد. صفر تعديل
على النواة. وهذا هو الفرق بين قابل للصيانة من شخص واحد، وغير قابل.

### الاكتشاف السريع للأعطال (شرط "أي مشكلة نكتشفها بسهولة")

| # | الآلية | الحالة |
|---|---|---|
| D1 | `healthcheck` كل ١٠ دقائق + تنبيه واتساب للأدمن | ✅ مبني |
| D2 | **معرّف طلب (request id) بكل سجل** — يربط الخطأ بالمستخدم والوقت | ⬜ يوم عمل |
| D3 | **صفحة `/api/admin/errors`** — آخر ٥٠ خطأ بمصدرها | ⬜ يوم عمل |
| D4 | **رسائل فشل عربية صريحة** لكل تدفق — صفر `429` خام للمستخدم | ⬜ |
| D5 | اختبارات منطق حقيقية (عزل المتاجر، التواقيع، الحصص) | ⬜ دَين موثّق |

**D2+D3 يُنفَّذان قبل أي ميزة جديدة.** بلاهما، كل عطل تحقيق يدوي يستهلك يوماً كاملاً —
وهذا لا يُحتمل على شخص واحد.

## الجزء ٢ — الاعتمادات: تُقدَّم الآن، لا حين نحتاجها

**المنطق:** الاعتماد وقت **انتظار** لا وقت **بناء**. تقديمه اليوم يعني أن الموافقة تصل
بينما نبني غيره. تأخيره يعني بناء جاهز ينتظر ورقة.

### 🥇 الأولوية القصوى — تطبيق Meta الواحد يفتح أربع قدرات

التطبيق `812182698552804` ("هالة") موجود ويعمل مع واتساب. **توسيع صلاحياته مراجعة
واحدة تفتح:**

| القدرة | الصلاحية المطلوبة | تخدم |
|---|---|---|
| واتساب (يعمل) | `whatsapp_business_messaging` + `whatsapp_business_management` | هالة واتساب |
| تعليقات إنستغرام | `instagram_manage_comments` | رد السوشيال |
| رسائل إنستغرام | `instagram_manage_messages` | رد السوشيال |
| إعلانات ميتا | `ads_management` / `ads_read` | الحملات (لاحقاً) |

**المطلوب منك — هذا الأسبوع:**
- [ ] **توكن System User دائم** (يفكّ حجب البوت الواقف منذ 2026-07-23) — ⚠️ **اليوم**
- [ ] التحقق من حالة **Business Verification** للحساب — شرط لأغلب الصلاحيات
- [ ] ربط حساب إنستغرام أورا بصفحة فيسبوك (شرط تقني لصلاحيات إنستغرام)
- [ ] تقديم طلب مراجعة للصلاحيتين الجديدتين + فيديو استخدام (يطلبه Meta)

> **درس موثّق من سلة:** المراجعة تأخذ أسابيع، وترفض لأسباب شكلية (فيديو ناقص،
> وصف غير واضح). قدّم مبكراً، وتوقع جولة تعديل واحدة على الأقل.

### 🥈 سلة — قيد المتابعة

### 🥉 تُقدَّم بالربع الأول 2027، لا الآن

**السبب:** كل واحد سطح صيانة دائم. لا تُقدَّم قبل أن تثبت قناة إنستغرام على عملاء

## الجزء ٥ — قواعد المطوّر الواحد

1. **كل تكامل خارجي ضريبة أبدية.** قبل أي تكامل: أقدر أصونه سنتين وحدي؟
2. **الفشل الرشيق قبل الميزة الجديدة.** انقطاع مزود الساعة ٢ ليلاً = رسالة مفهومة، لا انهيار.
3. **قِس قبل ما تبني التالي.** كل شهر: هل استُخدم ما بُني الشهر الماضي؟ لا = أصلحه.
4. **الأمن لا يُقصّ.** كل شيء آخر قابل للقص. تسريب بيانات على شخص واحد = نهاية المشروع.
5. **مهمة واحدة يومياً، منجزة ومنشورة ومُتحقَّقة.**
