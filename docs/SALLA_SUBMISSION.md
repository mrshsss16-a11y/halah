## ١) Basic Information — المعلومات الأساسية

**اسم التطبيق (عربي):**
```
هالة — أوصاف منتجات بالذكاء الاصطناعي
```

**اسم التطبيق (إنجليزي):**
```
Hala — AI Product Descriptions
```

**الوصف المختصر (سطر واحد):**
```
يقرأ صور منتجاتك ويكتب أوصافها بالعربي، جاهزة للسيو — تراجعها وتعتمدها بضغطة.
```

**الوصف الكامل:**
```
هالة تطبيق سعودي يحوّل صور منتجاتك إلى أوصاف بيع احترافية بالعربي.

كيف يعمل؟
اربط متجرك، تُسحب منتجاتك تلقائياً بصورها. اضغط أي منتج — هالة تحلّل صورته
فعلياً (اللون، القصّة، الياقة، الأكمام، التفاصيل الظاهرة) وتكتب وصفاً بلهجة
سعودية بيضاء مع عنوان بحث ووصف ميتا ونقاط بيع وأسئلة شائعة. تراجع النص،
تعدّله إن حبيت، وتعتمده فيُنشر على متجرك مباشرة.

ما يميّزه:
• يحلّل الصورة نفسها — لا يكتب من اسم المنتج وحده.
• مصطلحات أزياء دقيقة (ماكسي، قصّة A، ياقة V) بدل صياغات عامة.
• يذكر كل ألوانك ومقاساتك المتاحة، لا لون الصورة وحده.
• لا يخترع خامة ولا يدّعي جودة أو ضماناً لم تذكره أنت.
• ينبّهك لو كان تصنيف المنتج خاطئاً، ويصحّحه بضغطة بموافقتك.
• حدّد عدة منتجات واكتب أوصافها دفعة واحدة — وكل وصف يمرّ على مراجعتك.
• لا يُنشر شيء على متجرك قبل اعتمادك. ولك «تراجع» يرجّع وصفك الأصلي.

مناسب لمتاجر الأزياء والعبايات والمجوهرات والملابس.

مقدَّم من مؤسسة فريق أورا للتسويق — الرياض/مكة، السعودية.
```

**التصنيف:** التسويق / تحسين المنتجات (اختر الأقرب بالقائمة)

**الكلمات المفتاحية:**
```
وصف المنتجات · ذكاء اصطناعي · سيو · تحسين محركات البحث · أوصاف تلقائية
· تحليل الصور · أزياء · عبايات · مجوهرات · لهجة سعودية
```

### ⚠️ App Scope — أهم قرار بالملف

**المطلوب حالياً للتشغيل:**
```
products.read_write     ← قراءة المنتجات وتحديث أوصافها (جوهر التطبيق)
offline_access          ← تجديد التوكن بلا إعادة تسجيل التاجر
settings.read           ← اسم المتجر ووصفه (يُثري نبرة الوصف)
categories.read_write   ← قراءة التصنيفات وتصحيح الخاطئ منها بموافقة التاجر
```

**أضفها الآن ولو لم تُستخدم بعد** (ميزات مصمَّمة وتنتظر الصلاحية):
```
brands.read             ← العلامة التجارية (ترفع نسبة جودة المنتج بسلة)
shippings.read          ← مدد الشحن الحقيقية بدل الصمت عنها
payments.read           ← «الدفع عند الاستلام متاح» بصدق
specialoffers.read      ← اقتراح المكمّلات من عروض التاجر القائمة
marketing.read_write    ← كوبونات حصرية (مرحلة لاحقة)
```

> **لماذا الآن:** إضافتها اليوم = دقيقة بالبوابة. بعد النشر = **كل تاجر ربط
> يعيد الموافقة**، وقد يرفض. الصلاحية غير المستخدمة لا تضرّ؛ الصلاحية الناقصة
> تعطّل ميزة كاملة.

## ٣) App Features — المزايا

```
١. تحليل صورة المنتج فعلياً
   يقرأ اللون والقصّة والياقة والأكمام والتفاصيل الظاهرة، ويكتب وصفاً مبنياً
   عليها — لا من اسم المنتج وحده.

٢. مصطلحات أزياء دقيقة
   كتيب مصطلحات سعودي: ماكسي · قصّة A · ياقة V · كلوش · بذيل حورية — بدل
   «فستان طويل» العامة، فتتّسق التسمية عبر كل منتجاتك.

٣. حزمة سيو كاملة مع كل وصف
   عنوان بحث ووصف ميتا ونبذة تحت اسم المنتج ونقاط بيع وأسئلة شائعة — تُنشر
   كلها مع الوصف على سلة.

٤. كل ألوانك ومقاساتك
   يقرأ خيارات المنتج من متجرك ويذكر المدى المتاح، لا لون الصورة وحده.

٥. تصحيح التصنيف الخاطئ
   ينبّهك لو كان المنتج مصنَّفاً تحت فئة غير مطابقة، ويصحّحه بضغطة — مع
   إبقاء تصنيفاتك التسويقية كما هي.

٦. المعالجة بالجملة مع مراجعة فردية
   حدّد عدة منتجات، تُولَّد أوصافها بالخلفية، وتراجع كل واحد على حدة:
   تعتمده أو تعدّله أو ترفضه.

٧. لا نشر بلا اعتمادك
   كل وصف يمرّ على بوابة مراجعتك. ولك «تراجع» يرجّع وصفك الأصلي بعد النشر.

٨. صدق المحتوى
   لا يخترع خامة ولا يدّعي جودة أو ضماناً أو مدة شحن لم تذكرها أنت.
```
