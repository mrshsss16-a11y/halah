## خانات التاجر المستخدمة

السجل الكامل مستخرج آلياً من البيانات: `placeholders.json` (كل خانة، عدد مرات استخدامها، وأين تُستخدم).
الأكثر استخداماً: `{الخامة}` `{سياسة_الإرجاع}` `{الوزن}` `{الحجم}` `{المكونات}` `{المقاس}` `{شروط_العرض}`
`{عدد_القطع}` `{رقم_التواصل}` `{مدة_الاسترداد}` `{مدة_الضمان}` `{رابط_تتبع_الطلب}`.

ردود المبيعات وحزمة السياسات تستخدم خانات إنجليزية (`{product_specs}`، `{return_policy_summary}`، `{sla_urgent}`…)؛
توحيدها بالعربية قرار عند تفعيل البوتات.

## قرارات مفتوحة للمالك

1. **ردود المبيعات**: الأصل كان عن حجز استشارة هالة نفسها (وكالة)، والتنقيح حوّل 20 منها لمبيعات متجر.
   الأصل محفوظ بالنسخة الخام إن أُريد لبوت هالة التسويقي.
2. **السعر ببوت المتجر**: قاعدة «البوت لا يذكر رقم سعر» تتعارض مع سؤال عميل المتجر «بكم؟» — المقترح:
   الإحالة لسعر صفحة المنتج.
3. **عيوب منهجية بالأصل**: تصنيفات خاطئة واسعة (ملابس أطفال تحت «بخور وعود»، أدوات قهوة تحت «تمور»)،
   وعود مخترعة («التوصيل 1-3 أيام»، «إرجاع مجاني»)، وطلب بيانات حساسة (آخر 4 أرقام البطاقة) — كلها
   صُحّحت أو حُذفت؛ حقل التصنيف بالأصل غير موثوق.
