# تقييم مخاطر نقل البيانات الشخصية إلى خارج المملكة — هالة

> وفق لائحة نقل البيانات الشخصية إلى خارج المملكة: الغرض والمسوغ النظامي، وصف طبيعة النقل
> (أنشطة المعالجة ونطاقها الجغرافي)، والوسائل والضمانات المتخذة ومدى كفايتها لمستوى حماية لا
> يقل عن النظام. أُعدّ 2026-09-13. يُراجع عند إضافة مزوّد أو تغيير ما يُرسل إليه.

## القاعدة المشتركة لكل النقل

- **الغرض:** تشغيل خدمة يطلبها التاجر (استضافة، تحليل صورة منتج، توليد وصف، إرسال رسالة حساب).
- **المسوغ:** تنفيذ الخدمة المتعاقد عليها مع التاجر وبالصلاحيات التي منحها عبر سلة.
- **الحد الأدنى:** لا يُرسل لمزوّدي الذكاء الاصطناعي بريد التاجر ولا اسمه ولا أي بيانات عملاء؛
  يُرسل اسم المنتج ومزاياه وخياراته وصورته فقط. الصورة لا نخزّنها.
- **ضمانات تقنية:** كل نقل عبر HTTPS؛ مفاتيح المزوّدين أسرار بيئة لا بالكود؛ نص التاجر يُعزل
  بتوجيه «بيانات غير موثوقة» قبل النموذج.
- **الشفافية:** كل مزوّد مسمّى بصفحة الخصوصية مع ما يُرسل إليه، والنقل خارج المملكة مذكور صراحةً.

## التقييم لكل مزوّد

| المزوّد | الموقع | ما يُنقل | بيانات شخصية؟ | الضمانات | المخاطر | التقييم |
|---|---|---|---|---|---|---|
| Cloudflare (Pages/D1/KV/Workers AI) | عالمي | كل بيانات الخدمة المخزّنة، صور المنتجات للتحليل | نعم (حساب التاجر؛ أشخاص محتملون بالصور) | اتفاقية معالجة وشروط Cloudflare؛ تشفير توكنات سلة؛ عزل كل متجر | موقع التخزين غير مقيّد بالمملكة | **مقبول** مع توثيق اتفاقية المعالجة |
| Groq | الولايات المتحدة | نص المنتج، ملاحظات الصورة، صورة المنتج احتياطياً | محتمل (أشخاص بالصور) | لا يُرسل أي معرّف تاجر؛ صورة واحدة لكل طلب | سياسة احتفاظ المزوّد بالمدخلات | **مقبول بشرط** مراجعة شروط احتفاظ Groq |
| Google — Gemini API (**الطبقة المجانية**) | الولايات المتحدة | نص المنتج وملاحظات الصورة فقط (**لا صور** منذ 2026-09-13) | لا (لا يُرسل بريد ولا اسم ولا صورة) | إفصاح بصفحة الخصوصية؛ الصور مستبعدة بالكود (`ai/vision.js` بلا طبقة Gemini) | شروط الطبقة المجانية تسمح باستخدام نص المنتج لتحسين منتجات Google — بيانات منتج لا بيانات شخصية | **مقبول للنص.** الصور أُخرجت بقرار المالك 2026-09-13 |
| OpenRouter (نماذج مجانية) | الولايات المتحدة + مزوّد النموذج المختار | نص المنتج، ملاحظات الصورة، صورة المنتج احتياطياً | محتمل | لا معرّفات تاجر | المدخلات تمر بمزوّد النموذج (Google/NVIDIA…) بشروطه؛ النماذج المجانية قد تسجّل المدخلات | **مقبول بشرط** تفعيل إعدادات منع تسجيل المدخلات بحساب OpenRouter إن توفرت |
| Resend | الولايات المتحدة | بريد التاجر ونص رسالة الحساب | نعم (البريد) | يُرسل فقط بطلب التاجر؛ بلا تسويق؛ الرابط صالح ٣٠ دقيقة | سجل الرسائل لدى المزوّد ٣٠ يوماً (الطبقة المجانية) | **مقبول** |
| سلة | المملكة | طلبات قراءة المنتجات ونشر الأوصاف المعتمدة | بيانات التاجر | الصلاحيات التي منحها التاجر؛ توقيع الويبهوك | — | داخل المملكة — لا ينطبق |

## قرارات مطلوبة

1. ~~Gemini والصور~~ — **نُفّذ 2026-09-13:** Gemini للكتابة فقط، وصور المنتجات لا تُرسل إليه.
2. **OpenRouter:** مراجعة إعداد تسجيل المدخلات بالحساب.
3. **Groq:** توثيق سياسة الاحتفاظ بالمدخلات من شروطه الحالية.
4. **Cloudflare/Resend:** حفظ نسخة من اتفاقيات معالجة البيانات لديهما مع هذا الملف.
