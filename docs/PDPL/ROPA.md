# سجل أنشطة معالجة البيانات الشخصية — هالة

> وثيقة داخلية وفق نظام حماية البيانات الشخصية ولائحته التنفيذية (عناصر السجل: الجهة وبيانات
> التواصل، الأغراض، فئات البيانات وأصحابها، مدد الاحتفاظ، الجهات التي يُفصح لها). أُعدّت
> 2026-09-13 من المخطط الفعلي (`migrations/*.sql`) والكود، لا من الوثائق. تُحدَّث مع أي جدول أو
> مزوّد جديد.

## ١. جهة التحكم

| البند | القيمة |
|---|---|
| الجهة | مؤسسة فريق أورا للتسويق (تطبيق «هالة») |
| التواصل | info@aura.sa |
| الموقع | https://halah.aura.sa |
| مسؤول حماية البيانات | لم يُعيَّن بعد — يُحسم بأداة «مدى إلزامية تعيين مسؤول حماية البيانات» في منصة حوكمة البيانات الوطنية |

**الأدوار:** هالة **جهة تحكم** لبيانات حساب التاجر (بريده وكلمة مروره). ولبيانات متجره (منتجاته
وصورها) تعالج **نيابةً عن التاجر** ولغرض الخدمة وحده — والتاجر جهة التحكم لأي بيانات شخصية تظهر
فيها (مثل صورة عارضة يمكن التعرف عليها).

## ٣. فجوات مفتوحة من هذا السجل

1. **مدة احتفاظ `audit_log` و`consultation_bookings`** غير محددة ولا يُتلفان آلياً — يخالف مبدأ «الإتلاف بعد انتهاء الغرض دون تأخير».
2. ~~صور أشخاص عبر Gemini API المجاني~~ — **أُغلق 2026-09-13:** الصور لا تُرسل لـGemini.
3. **مسؤول حماية البيانات والتسجيل بمنصة حوكمة البيانات الوطنية**: لم يُحسما.
4. **`login_attempts`**: لا تقليم زمني للصفوف القديمة (القفل ينتهي، الصف يبقى).
