# أرشيف: ميزات خارج النطاق الحالي

> **لا يُبنى ولا يُنشر.** محفوظ كمرجع فقط — كود شغّال وقت الأرشفة، ليس معطوباً.
> تاريخ: 2026-08-06.

## القرار

المشروع يركّز حصراً على ثلاث ركائز (**full modular** — كل ركيزة تعمل بمعزل، بلا تشابك):

1. **كتابة وصف منتجات مثالي** — سوق سعودي + SEO (`functions/api/copy.js`)
2. **وكلاء خدمة عملاء واتساب + متاجر** — أعلى سرعة، أعلى جودة، لهجة سعودية بيضاء
   (`functions/api/whatsapp/*`, `functions/api/chat.js`, `functions/api/support.js`)
3. **بوابة حسابات** — تسجيل/دخول/إدارة (`functions/api/auth/*`, `functions/_lib/core/session.js`)

كل ما دون ذلك أُرشف — ليس لأنه سيئ، بل لأنه **لم يُطلب ولم يُتحقق منه** (راجع
`docs/PRODUCT_PLAN.md`: صفر استخدام حقيقي لأي من هذي الميزات وقت الأرشفة).

## المحتوى وسبب كل واحدة

| الملف | لماذا أُرشف |
|---|---|
| `store/{zatca,voice,ocr,broadcast,campaign,digest,ingest,recovery,cart_recovery,sandbox,instant_agent,report}.js` | أدوات إضافية خارج الركائز الثلاث — بعضها كان موصولاً بـ`dashboard.html` القديم، أُزيلت الواجهة معه |
| `scan.js` | صفحاته (`scanner.html`, `results.html`) محذوفة من قبل — orphan |
| `trendyol/*`, `_lib/integrations/trendyol.js`, `webhooks/trendyol.js` | صفر أسرار، صفر واجهة، صفر ربط — سوق مختلف عن التموضع الحالي (تركي مقابل سعودي) |
| `auth/zid/*`, `_lib/integrations/zid.js` | مُقرَّر لاحقاً بترتيب سلة ← زد ← ترينديول؛ حالياً بلا أسرار مضبوطة، مكسور لو استُخدم |
| `webhooks/shipping.js` | تتبع شحن — خارج الركائز الثلاث |
| `admin/project.js` | لوحة "حالة مشروع" تضمّنت ادعاءات وهمية (أسماء وكلاء، تقنيات Groq/DeepSeek بدون مفاتيح فعلية) — يخالف قاعدة الصدق |
| `navbar.html` | غير مستخدم بأي صفحة، وألوانه (بنفسجي-نيلي) تخالف الهوية المعتمدة (تيل/أزرق) |

## متى نعيد النظر

أي ميزة هنا تُستعاد فوراً بمجرد وجود طلب حقيقي (تاجر سأل عنها، أو قرار عمل صريح) —
انسخها من هنا لمكانها الأصلي، أعد ربطها بالواجهة، وأزل هذا القيد من `stage.mjs`
(مستثناة أصلاً لأن `docs/` خارج البناء).

## قاعدة بيانات ملاحظة

جداول D1 المرتبطة بهذي الميزات (`product_sync` لترينديول مثلاً) لم تُحذف — تبقى فارغة
بلا ضرر حتى قرار لاحق.
