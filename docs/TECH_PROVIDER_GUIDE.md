## قبل ما تبدأ

رابط تطبيقك المباشر: **https://developers.facebook.com/apps/812182698552804**

احفظه — كل خطوة بالدليل تبدأ من هنا.

## الخطوة ١ — إصلاح إعدادات التطبيق (٥ دقائق)

**وين:** من الرابط أعلاه → القائمة اليسار → **Settings → Basic**

على هالصفحة، عدّل ٣ حقول:

| الحقل | وش تسوي |
|---|---|
| **Privacy Policy URL** | تأكد إنه `https://halah.aura.sa/privacy.html` (موجود أصلاً غالباً — تحقق بس) |
| **Terms of Service URL** | غيّره من `facebook.com` لرابط حقيقي — لو ما عندك صفحة شروط، اكتب رابط لصفحة بسيطة بموقع أورا تشرح شروط استخدام هالة |
| **Data Deletion URL** | نفس الشي — رابط حقيقي يشرح كيف يطلب المستخدم حذف بياناته |
| **App Category** | تأكد إنها فئة حقيقية (مثلاً "Business"), مو "ALL" |
| **App Purpose** | اختر **"Yourself or Your Own Business"** ← ثم لازم تغيّرها لـ**"Clients"** لأن التطبيق يخدم تجار سلة لاحقاً، مو أورا بس |
| **Business Email** | تأكد فيه إيميل صحيح مكتوب |

اضغط **Save Changes** أسفل الصفحة.

**بعدها:** روح لصندوق الإيميل اللي كتبته (`aurateam3@gmail.com` على الأغلب) ودوّر رسالة من ميتا فيها رابط تأكيد — اضغطه.

**معيار الإنجاز:** ترجع لنفس الصفحة، تشوف علامة ✅ أو "Verified" جنب الإيميل.

---

## الخطوة ٢ — الدخول لمسار Tech Provider (دقيقتين)

**وين:** من نفس التطبيق → القائمة اليسار → **Use cases**

بتشوف بطاقة اسمها تقريباً **"التواصل مع العملاء عبر واتساب"** أو **"Communicate with customers via WhatsApp"**.

⚠️ **لا تضغط على أي زر "Add Use Cases" أو "إضافة حالات استخدام"** — هذا مسار غلط.

**اللي تسويه:** على نفس البطاقة، دوّر أيقونة **قلم صغير (✏️) أو "Customize"** — عادة بأعلى يمين البطاقة أو جنبها. اضغطها.

بتفتح لك صفحة جديدة فيها قائمة يسار. دوّر فيها بند اسمه:

**"Tech Provider onboarding"**

اضغطه.

**معيار الإنجاز:** تشوف صفحة عنوانها شي زي "Become a Tech Provider" أو خطوات مرقّمة (Step 1, Step 2...).

---

## الخطوة ٣ — تخطي التحقق من النشاط (تلقائي)

بهالصفحة بتلقى **"Step 1: Verify your business"**.

**لا تسوي شي هنا** — النشاط موثّق أصلاً (Business Verification ناجح من قبل). اضغط **Next** أو **تخطي** لو موجود، وانتقل للخطوة اللي بعدها.

---

## الخطوة ٤ — طلب المراجعة (App Review)

بتشوف **"Step 2: App Review"**. هذا الجزء الأطول، وفيه ٣ أقسام:

### ٤.أ — إعدادات التطبيق
غالباً تشوف علامة ✅ لو خلّصت الخطوة ١ صح. لو فيه تحذير أحمر، ارجع للخطوة ١ وشوف وش ناقص.

### ٤.ب — طلب الصلاحيات
بتلقى صلاحيتين مطلوبتين، موجودتين أصلاً بطلبك (بس ناقصتهم فيديو):

- `whatsapp_business_messaging`
- `whatsapp_business_management`

لكل وحدة فيها زر أو رابط "How will your app use this permission" — لازم:
1. تكتب وصف قصير (سطرين تكفي): *"نستخدم هذي الصلاحية لإرسال واستقبال رسائل واتساب آلية لخدمة عملاء أورا وتجار سلة المرتبطين"*
2. **ترفع فيديو** — شوف الخطوة ٥ تحت قبل ما تكمل هنا

### ٤.ج — التحقق (App Verification)
يطلب منك تشرح لمراجعي ميتا كيف يجربون تطبيقك. اكتب خطوات بسيطة:
*"التطبيق backend فقط، لا واجهة تسجيل دخول عامة. للتحقق من واتساب: أرسل رسالة لرقم [رقم أورا] وشاهد الرد الآلي."*

## الخطوة ٥ — تسجيل الفيديوهين (الجزء اللي يحتاج وقت)

**لازم فيديوهان منفصلان — دمجهما بفيديو واحد = رفض.**

### فيديو ١ — لصلاحية `whatsapp_business_messaging`

**وين تسجّل:** نفس التطبيق → **WhatsApp → API Setup** (بالقائمة اليسار)

**وش تسوي بالتسجيل:**
1. افتح برنامج تسجيل شاشة (Windows: `Win + Alt + R` يفتح تسجيل سريع، أو أي برنامج تعرفه)
2. افتح صفحة API Setup
3. فيها حقل "To" وزر "Send Message" جاهز لإرسال رسالة اختبار — اضغطه
4. افتح واتساب على جوالك أو الويب (`web.whatsapp.com`) وأنت مسجّل تسجيل الشاشة، ووري إن الرسالة وصلت فعلياً
5. أوقف التسجيل

**الطول المناسب:** ٣٠-٦٠ ثانية.

### فيديو ٢ — لصلاحية `whatsapp_business_management`

**وين تسجّل:** [WhatsApp Manager](https://business.facebook.com/wa/manage/home) → **Account tools → Message Templates**

**وش تسوي بالتسجيل:**
1. ابدأ تسجيل الشاشة
2. اضغط **"Create Template"**
3. عبّي اسم القالب ونوعه (اختر أي فئة، مثلاً Utility) واكتب نص بسيط
4. اضغط **Submit** ووري إنه انحفظ (تظهر بالقائمة بحالة "Pending" أو "In Review")
5. أوقف التسجيل

**الطول المناسب:** ٣٠-٦٠ ثانية.

**احفظ الفيديوهين بصيغة MP4 أو MOV** بمكان تلقاه بسهولة.

## الخطوة ٦ — رفع الفيديوهين وإرسال الطلب

ارجع لصفحة App Review (الخطوة ٤)، بكل صلاحية بتلقى مكان رفع فيديو (زر "Upload" أو "Add Screencast"). ارفع الفيديو المناسب لكل صلاحية.

بعد ما ترفع الاثنين وتتأكد كل الحقول مكتملة (صفر علامات حمراء)، بيظهر زر **"Submit for Review"** أو **"Continue to App Review"**.

اضغطه.

**معيار الإنجاز:** تشوف حالة الطلب تتحول لـ **"In Review"** أو **"Pending"**.

## بعد الإرسال

- المراجعة عادة **~٢٤ ساعة** (حسب توثيق ميتا)، ممكن تطول لبضعة أيام
- بتوصلك رسالة إيميل بالنتيجة
- لو انرفض: الإيميل يوضح السبب — أغلب الأسباب الشائعة: فيديو مو واضح، أو دمج صلاحيتين بفيديو واحد. صحّح وأعد الإرسال

**بينما تنتظر:** الكود جاهز أصلاً بجهتنا (بُني ومختبر) — ما يحتاج شي إضافي منك غير انتظار الموافقة.
