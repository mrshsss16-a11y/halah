## مبادئ لا تُكسر أثناء التنفيذ

1. **لا إطلاق موسّع قبل تحقق معايير الخروج** — الإطلاق المحدود يكشف الأعطال بأمان.
2. **لا ميزة جديدة قبل وصل الميزات القائمة** — نمط تكرر أكثر من مرة (الاستوديو،
   consultation، والآن ودجت الموقع) يكفي كدرس.
3. **الصدق شرط إطلاق** — لا رقم ولا ادعاء غير حقيقي، ولو بدا العدّاد فارغاً.
4. **كل نشر يمرّ بـ `npm run deploy`** — الحارس يمنع إسقاط الـ API.
5. **لا تُضعف الأمن لتسريع الإطلاق** — الأساس الأمني أثمن ما بُني.
