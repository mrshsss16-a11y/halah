# Hala AI OS — Public Recovery Snapshot

هذه لقطة استرداد للواجهة العامة التي كانت متاحة علناً على `https://halah.aura.sa/` في 12 أغسطس 2026. أُنشئت بهدف حفظ هيكل الواجهة والنصوص العامة والاتجاه البصري في مستودع قابل للمراجعة، وليست المصدر الأصلي لتطبيق هالة.

> **لا تنشر هذه اللقطة على الإنتاج كما هي.** لم يُسترد من Cloudflare منطق الخادم أو دوال Pages أو بيانات D1 أو مفاتيح البيئة أو KV أو Vectorize أو التكاملات مع سلة وواتساب ومزودي الهوية.

## المحتوى المتاح

| المسار | المحتوى | حالة الوظائف |
|---|---|---|
| `index.html` | صفحة الهبوط العامة | روابط وطلبات الخادم عُطلت عمداً داخل اللقطة. |
| `login.html` | واجهة الدخول العامة | حقول الدخول والربط محفوظة بصرياً، والمنطق الخادمي عُطل عمداً. |
| `RECOVERY_LIMITATIONS.md` | ما تعذّر استرداده وخطة استكماله | مرجع إلزامي قبل التطوير. |

## طريقة المعاينة

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً ثابتاً محلياً. تعتمد الصفحات على خطوط ومكتبات CDN عامة، وقد لا تعمل بعض المؤثرات بلا اتصال بالإنترنت.

## الخطوة الصحيحة بعد حفظ اللقطة

يجب إعادة بناء المصدر كـ Next.js/Cloudflare Pages مشروع قابل للصيانة، ثم نقل منطق المصادقة وواجهات API وتكامل سلة وواتساب وD1 وKV وVectorize من مصدر موثق أو إعادة تنفيذ مدققة. لا تضف أسراراً إلى Git؛ استخدم إعدادات Cloudflare Pages وملف `.env.example` فقط.
