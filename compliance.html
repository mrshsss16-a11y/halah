المعيار البرمجي الوصف المتوافق الحالة
نوع التفويض Authorization Code Grant Flow مطابق
التحقق والمصادقة Client ID & Client Secret عبر خادم هالة الآمن مطابق
الصلاحيات (Scopes) طلب offline_access لضمان استدامة الـ Refresh Token مطابق
أمان الرموز (Tokens) تشفير مغلف (KEK/DEK) للرموز قبل حفظها في قاعدة البيانات مطابق

جاهز للتكامل

يعتمد الربط مع ترينديول على مصادقة **HTTP Basic Authentication** باستخدام معلومات التكامل المأخوذة من لوحة الشريك.

المعيار البرمجي الوصف المتوافق الحالة
نوع التفويض HTTP Basic Auth (Base64 key:secret) مطابق
مترادفات الترويسة (Headers) إلزامية ترويسة User-Agent: {SellerId} - SelfIntegration مطابق
بيئة الاختبار (Stage) تتطلب تفويض عناوين الـ IP الخاصة بالخادم مسبقاً يتطلب إجراء IP
حدود الطلبات (Rate Limits) 50 طلباً كحد أقصى لكل 10 ثوانٍ (التحكم بالتدفق مفعّل) مطابق
المرجع: developers.trendyol.com/v5.0 تم التحقق من تكامل مسارات Dashboard.html
